Admin buttons — pick a style

Three less-childish treatments for the admin pages. Reply with A, B, or C.

Today (for comparison)

Playful pill

Bright-pink full pills with a coloured glow. Great for the kids' app, a bit childish for admin.

Option A

Professional solid

Squared corners (8px), flat — no coloured glow. Calm dark-slate primary, white outlined secondary. Clean SaaS admin feel.

Option B

Outline / ghost

Most restrained. One accent-filled primary; secondary is an outlined button; minor actions are text-only. Light and airy.

Option C

Neutral monochrome

Greyscale chrome: slate primary, light-grey secondary, square-ish (6px). No pink on admin buttons at all — colour is saved for status chips. Most businesslike.
