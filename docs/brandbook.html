§13 · Rules

Do / Don't

✓ Do
  • ✓ Use --ink (#2D2A4A) for text, never pure black
  • ✓ Use --bg (#FAF8F5) for app background, white for cards only
  • ✓ Use --pink-dark for denial / errors (kind, not aggressive)
  • ✓ Always tabular numerals for counts, balances, dates
  • ✓ Logical CSS properties (ps-*, pe-*) — never pl-*/pr-*
  • ✓ One language per screen (Hebrew default, English via toggle)
  • ✓ Embroidered patch only for badges — circular, dashed border, white count chip
  • ✓ Every meaningful icon needs an aria-label
✗ Don't
  • ✗ Use pure black #000 or pure white #FFF at app bg level
  • ✗ Use the color red anywhere — pink-dark covers denial states
  • ✗ Mix Lia's peach + Yael's sky on the same component
  • ✗ Use emoji for badges or rewards in production
  • ✗ 3D silver shields or hanging-medal ribbons (rejected at Gate 3)
  • ✗ Hardcoded Hebrew/English text in components — use dictionaries
  • ✗ Animations > 500ms outside celebration moments
  • ✗ Red flash / shake effects for errors — soft denial only
  • ✗ Proportional numerals for counts (always tabular)
  • ✗ Fonts outside Fredoka / Heebo / Quicksand — ever
