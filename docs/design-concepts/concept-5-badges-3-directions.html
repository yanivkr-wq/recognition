A

Embroidered patch

Flat circular patch with a stitched dashed outer ring. No 3D, no metallic surface — pure flat-illustration. The dashed border evokes embroidery/iron-on patches like Girl Scout merit badges or enamel pins. Soft, casual, tactile. Count chip below the patch in a small white pill. Best when: you want the kid app to feel playful and tactile — like a sticker album the kid is filling. Lowest visual weight; tiles well in dense grids.

B

Hanging medal

Vertical layout. Fabric ribbon strap at the top (color-coded per badge category) folds into a gold-rimmed medallion. Inner field is white with the illustrated emblem centered. Earned count engraved at the bottom of the medal rim. Locked state is a gray medallion on a gray ribbon. Best when: you want the kid to feel like she's earning real awards — a trophy room. Higher visual weight per badge; tiles less densely; works in a 3-column grid.

C

Collectible card

Portrait card with a colored top section (illustrated emblem + count chip + rarity tag) and a white bottom section (badge name + tiny description + bonus coin chip + year earned). Reads like a Pokémon or trading card. Locked cards show "??" with the emblem grayed out under a dashed border. Best when: you want a true collection mentality — kid swipes through cards, compares with sibling, has favorites. Highest content density per badge. Tiles in 2-col on phone. Each badge feels like a discrete artifact.

— recommendation —

If I had to pick: C · Collectible card

The collectible card is the only direction where each badge is a discrete artifact, not just a tile in a grid. It carries name, description, count, rarity, year, and coin bonus all in one container. That density unlocks UX moves the other two can't: tap-to-flip for a back-of-card view, swipe-through deck navigation, "favorites pinned to top," even sibling-trade fantasy (Lia and Yael compare their decks).

A · Patch is closest to the original Child Reward reference and tiles densest — best if your design philosophy is "more visible badges = more pull." But each patch is information-light; you need a detail page to do anything useful with one.

B · Medal is the most "premium award" feel. Best if Reco wants badges to read as serious achievements. Each one carries weight visually but its information density is lowest — the ribbon-strap header eats space.

Honest caveat: C inherits less from the Child Reward DNA than A or B. If matching that reference closely was important, A (patch) wins on visual heritage. But for Reco's specific feature set (campaigns produce badges with bonus coins + dates + descriptions), C's information architecture is the right shape.
