Concept 05 · v2 — Plush, with custom illustrated iconography

Plush v2

Same architecture as Plush v1 — soft pastels, white cards, pink CTAs, vertical task timeline, 3D metallic shield badges. Net change: every icon is now custom-illustrated SVG. Avatars are real character illustrations. Badge emblems are geometric inlays. Task icons are flat-illustrated objects. Rewards are designed product icons with depth, color, and personality — the polish you'd expect from a real reward-app icon set.

— concept 05 v2 notes —

What changed from v1

Three icon families, all custom SVG: (1) character avatars — fox for Lia, bunny for Yael, flat-illustrated heads with personality; (2) badge emblems — 8 geometric inlays (bee, book, star, music note, flame, cake, diamond, crown) that sit inside the 3D metallic shield; (3) reward icons — 6 designed product illustrations (wrapped candy, phone, ice cream, pillow, movie ticket, game controller) with 2-3 colors and depth; (4) task icons — 5 flat-illustrated objects (bed, toothbrush, croissant, shirt, camera) on colored backgrounds. Plus a proper coin icon (gold gradient, ¢ symbol).

To save preview-file size I showed 3 screens (profile picker, kid home, badge collection + shop). The other 5 screens follow the same icon-system rules — same avatars, same task icons, same reward icons, same badge emblems. If you pick this concept, every screen gets the same treatment.
